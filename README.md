# 🚀 CardioInsight

### *AI-Based Heart Disease Prediction & ML Model Analytics Dashboard*

---

## 🧠 Project Overview

CardioInsight is an AI-powered healthcare analytics project that combines Machine Learning and Power BI to predict heart disease risk and evaluate model performance.

This project goes beyond prediction by providing a comparative analysis of multiple ML models through an interactive dashboard, helping identify the most reliable model.

---

## 🎯 Objectives

* Predict heart disease using ML algorithms
* Compare multiple models based on performance metrics
* Identify the best-performing model
* Visualize insights using Power BI
* Enable data-driven decision making

---
